# 🍎🥕 Fruit & Vegetable Image Classification

A deep learning-based image classification system built using TensorFlow that classifies images of different fruits and vegetables. The trained neural network is deployed as a web application for real-time image classification.

---

## 📌 Overview

Image classification is a computer vision task where a machine learning model learns to identify the category of an image.

In this project, a Deep Learning Neural Network is trained on a dataset of fruit and vegetable images. The system processes the input image, extracts useful patterns through multiple neural network layers, and predicts the corresponding fruit or vegetable category.

The trained model is finally deployed as a web application where users can upload an image and receive the predicted class.

---

## 🎯 Objectives

- Build an image classification model using Deep Learning.
- Preprocess and prepare image data for training.
- Train a neural network using TensorFlow.
- Evaluate the performance of the trained model.
- Predict the class of unseen images.
- Deploy the trained model as a web application.
